Cursor 下用 npx 搭建 MySQL / Redis MCP（Windows + 远程库）

发表于2026-08-24|更新于2026-08-24|工具
|浏览量:

在 Java / Spring Boot 日常开发里，Cursor Agent 如果能直接读 Apifox 文档、查 MySQL 表结构、看 Redis key，比手动贴 DESCRIBE、复制会话快照省事得多。本文整理一套 Windows + npx + 远程库 的 MCP 搭建笔记，踩过的坑一并写上。

1. MCP 是什么

MCP（Model Context Protocol）是 AI 客户端与外部工具之间的开放协议。Cursor 通过 mcp.json 启动本地进程（或连远程 HTTP 服务），把数据库、IDE、API 文档等能力暴露给 Agent。

配置文件位置：

范围 路径
全局 ~/.cursor/mcp.json
项目 .cursor/mcp.json

改完需 完全退出 Cursor 再打开，在 Settings → MCP 确认服务为绿色。

2. 国内 Java 开发常用 MCP（节选）

MCP 用途
JetBrains MCP IDEA 2025.2+ 内置，读代码、运行配置、调试、Database Tools
Apifox MCP 让 AI 按接口文档写 Controller / DTO
MySQL MCP 查表结构、跑 SELECT
Redis MCP 查 key、TTL、Hash / List 等
GitHub MCP Issue、PR、读仓库

MySQL / Redis 若走 npx，内存大约每个 50～120 MB，比 Docker Desktop 轻，单人开发够用。

  • Node.js ≥ 20（@benborla29/mcp-server-mysql 要求 v20+）
  • 远程 MySQL / Redis 已开 公网或 VPN，本机 IP 已加 白名单
  • PowerShell 验证端口：

需看到 TcpTestSucceeded : True。

MySQL 只读账号（建议）

5. mcp.json 完整示例（Windows + 远程）

说明：

  • Windows 下 command 用 cmd + /c npx，比直接 npx 更稳。
  • MySQL 必须配 MYSQL_DB，否则 MCP 能起但不好查表。
  • Redis 密码格式：redis://:密码@主机:端口/db，密码前的冒号不能省。
  • 阿里云 Redis 公网端口不一定是 6379，以控制台为准（例如 10399）。
  • 密码含 #、@ 等需 URL 编码（# → %23）。

MySQL 在 Cursor 里仍失败时：mcprunner

6. 两个 MCP 分别能做什么

mysql-test

能力 示例
查表结构 「列出所有表」「看 xxx 表字段」
执行 SELECT 「查最近 10 条记录」
写操作 默认关闭，需显式开 env 开关

redis-test

能力 示例
get / set / del 读写 key
keys 按 pattern 查 key
ttl / type 过期时间、数据类型
hgetall / lrange 等 Hash、List、Set
dbsize / info key 总数、实例信息

对话里带上 server 名，避免搞混：用 mysql-test 列出所有表、用 redis-test ping。

7. 连接多个数据库

做法一：多个 MCP 条目（推荐）

同一 mcpServers 里加多个名字即可，例如 mysql-test、mysql-prod、redis-test、redis-prod。同一 RDS 多库时，只改 MYSQL_DB：

Redis 多 db：URL 末尾改 /0、/1。

命名建议带环境：mysql-test-card、redis-prod-session，避免 AI 用错库。

做法二：MySQL Multi-DB 模式

@benborla29/mcp-server-mysql 支持 Multi-DB（见官方 README-MULTI-DB.md），一个进程管多个 MySQL 源，配置较复杂，适合源很多、想少占进程时再用。

8. Docker vs npx（简要）

npx Docker 跑 MCP
内存 ~50–120 MB / 进程 Docker Desktop 常驻常 1GB+
启动 首次下载包 10～30s 拉镜像 + 起容器更慢
适用 单人本地开发 隔离、团队统一环境

推荐：数据库可以 Docker，MCP 本身用 npx 最省事。

9. 常见报错排查

现象 原因 处理
could not determine executable to run Redis 包名错 改用 @gongrzhe/server-redis-mcp@1.0.0
Socket closed unexpectedly 端口错 / 白名单 / SSL 核对控制台端口；加 IP 白名单；SSL 实例可能需 rediss:// + 支持 TLS 的包
MySQL Access denied 账号、库名、密码 补 MYSQL_DB；客户端先测登录
Connection timed out 未开公网 / 安全组 阿里云申请公网地址 + 白名单
MCP 不刷新 Cursor 未完全重启 退出进程再开；必要时 npm cache clean --force
spawn npx failed PATH 用 cmd /c npx 或 Node 绝对路径

阿里云 Redis 公网 checklist

  1. 控制台 公网地址 + 正确端口（不一定是 6379）
  2. 本机公网 IP 加入 白名单
  3. Test-NetConnection host port 为 True
  4. 有 SSL 时，明文 redis:// 可能被立刻断开

10. 验证步骤

  1. Settings → MCP 两个服务均为绿色
  2. View → Output → MCP 无启动错误
  3. 对话测试：
    • 用 mysql-test 列出所有表
    • 用 redis-test ping，并查 dbsize

PowerShell 侧可先验凭据（与 MCP 无关的直连测试）：

11. 安全

  • mcp.json 含密码，不要提交 git
  • 每个环境 单独只读账号，慎连生产
  • 白名单只加固定 IP，避免 0.0.0.0/0
  • 密码一旦出现在聊天 / 文档里，建议 轮换
